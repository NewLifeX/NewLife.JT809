# 多语言本地化

NewLife.JT809 的异常与日志复用 [NewLife.Core 的多语言机制](https://github.com/NewLifeX/X/blob/dev/Doc/多语言本地化.md)：**编译期生成词表、英文为源文与兜底、缺失译文自动回退英文**，不依赖 resx 与卫星程序集，单 DLL 且 AOT 安全。

## 1. 语言选择

| 设置 | 作用 |
|---|---|
| `CultureInfo.CurrentUICulture` | 默认语言来源 |
| `Localization.Culture` | 强制指定异常与常规文本语言；`null` 表示跟随 `CurrentUICulture` |
| `Localization.LogCulture` | 日志与配置注释的语言；`null` 表示跟随 `Culture` |

```csharp
// 全站中文
Localization.Culture = new CultureInfo("zh-CN");

// 日志保持英文，界面与异常跟随系统
Localization.LogCulture = new CultureInfo("en-US");
```

## 2. 语言清单

`NewLife.JT809/Locales/` 下每种语言一个 yml 文件，键为英文原文，值为译文：

| 区域 | 语言 |
|---|---|
| 东亚 | `zh-Hans`、`zh-Hant`、`ja`、`ko` |
| 西欧 | `de`、`fr`、`es`、`pt` |
| 其他 | `ru`、`ar` |

- 运行时词表共 **11 种语言**，其中英文为源文与兜底（不需要 `en.yml`），其余 **10 种**提供译文，README 徽章 `locales` 显示的即译文语言数。
- 语言代码按 BCP 47：简体 `zh-Hans`（承接 `zh-CN`/`zh-SG`）、繁體 `zh-Hant`（承接 `zh-TW`/`zh-HK`/`zh-MO`），其余按语言子标签回退（`de-AT` → `de`）。
- 未登记的语言自动回退英文源文，**缺译文不需要改代码**。

## 3. 使用约定

| 场景 | 写法 |
|---|---|
| 自定义异常 | `throw new XException("English template", args)` |
| BCL 异常 | `throw new InvalidOperationException(L.T("English template", args))` |
| 日志（整句模板） | `XTrace.WriteLine("English template {0}", arg)`，由 `Logger.Format` 自动翻译 |
| 手工拼装的日志片段 | `L.TLog("English fragment", args)` |

- **不要用字符串插值**（`$"..."`）：模板已经展开，无法再查表。
- 模板按**整句**查表，参数本身不会被翻译；不要把英文状态词作为 `{n}` 参数传入。
- `[Description]` 等特性文本属于元数据，不纳入运行时词表；写入 Xml/Ini 配置注释时由 Core 在保存阶段按语言翻译。

## 4. 词表校验

词表由随 `NewLife.Core` 主包分发的源生成器在编译期校验：

| 诊断 | 级别 | 含义 |
|---|---|---|
| LOC001 | Error | yml 行格式错误 |
| LOC002 | Error | 同文件键重复 |
| LOC003 | Error | 占位符与英文原文不一致 |
| LOC004 | Warning | 格式说明符不一致 |

新增词条时，必须**同步补进全部语言文件**，否则编译报 LOC003；新增语言只需追加 `<culture>.yml`，不需要改代码。

## 5. 测试

`XUnitTest/Localization_Tests.cs` 覆盖：简体中文命中词表、繁体中文命中词表、未登记语言回退英文、10 种语言均已注册。

> `Localization.Culture` 是进程级全局状态，改写它的测试必须放入串行集合（本仓使用 `[Collection("GlobalState")]`）。
